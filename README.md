# MiDiQE – Source Code Repository

This repository contains the source code accompanying the (to be published) paper:

> **Victor Hugo Nascimento Rocha, Fabio Gagliardi Cozman, and Serena Villata.**
> *Assessing the Minimal Dialectical Quality in Argumentation: A Neuro-Symbolic Approach Integrating Argument Mining, Quality Assessment, and Probabilistic Reasoning.*
> Journal of Artificial Intelligence Research (JAIR), 2026. 

The repository implements the **Minimal Dialectical Quality Evaluator (MiDiQE)**, a neuro-symbolic framework for assessing the argumentative quality of essays through the proposed **Minimal Dialectical Quality (MDQ)** criterion. The system integrates three main components:

1. **Argumentation Mining (AM)** – extraction of argumentative structures from text;
2. **Single Argument Quality Assessment (SAQ)** – estimation of Cogency and Reasonableness;
3. **Argumentation Reasoning (AR)** – symbolic probabilistic reasoning using BCAFs and L-credal semantics.

A conceptual overview of the complete system is provided in the paper.

# Overview of the Modules

## 1. Argumentation Mining (AM) Module

The AM module extracts argumentative structures from essays. It includes two complementary approaches:

### Linguistic Approach

Located in:

```text
AM Module/Linguistic Approch/
```

This implementation focuses on transformer-based linguistic modeling for:

* Span Identification
* Component Classification
* Link Detection
* Relation Classification

The implementation reflects the AM experiments discussed in Section 3.1 of the paper. 

The approach incorporates full-text contextual information during classification, following the methodology described in the paper. 

---

### GNN Approach

Located in:

```text
AM Module/GNN Approch/
```

This implementation explores graph neural network methods for argument relation modeling, particularly:

* Link Detection
* Relation Classification
* Component Classification

The GNN approach leverages the graph structure of argumentative discourse, as discussed in the paper’s AM section and appendices. 

---

## 2. Single Argument Quality Assessment (SAQ) Module

Located in:

```text
AQ Module/
```

The SAQ module predicts local argument quality metrics:

* **Cogency**
* **Reasonableness**

Two model families are implemented:

### BiLSTM Models

```text
AQ Module/BiLSTM/
```

Contains sequence-based neural architectures for both metrics.

---

### Random Forest Models

```text
AQ Module/Random Forest/
```

Contains the Random Forest implementations ultimately adopted in the MiDiQE pipeline due to their superior empirical performance. 

The preprocessing strategy used in these models encodes local argument graph structure into the textual input representation. 

---

## 3. Argumentation Reasoning (AR) Module

Located in:

```text
AR Module/
```

This module implements the symbolic reasoning component of MiDiQE using:

* Bipolar Conclusion-Augmented Argumentation Frameworks (BCAFs)
* L-credal semantics
* Probabilistic logic programming

The AR module computes the probability that a text satisfies the Minimal Dialectical Quality criterion. 

The implementation integrates probabilistic reasoning with outputs generated by the AM and SAQ modules. 

The provided scripts correspond to different experimental configurations:

| Script                                                    | Description                                                  |
| --------------------------------------------------------- | ------------------------------------------------------------ |
| `main_original_annotations.py`                            | Uses original annotations                                    |
| `main_original_annotations _predicted_quality_metrics.py` | Combines original annotations with predicted quality metrics |
| `main_pipeline_no_prob_predicted_quality.py`              | End-to-end pipeline configuration                            |

# Running the Code

The repository is organized experimentally rather than as a packaged software library. Each `main.py` file corresponds to a specific experiment or module configuration.

Typical execution pattern:

```bash
python main.py
```

or

```bash
python "main - relation classification.py"
```

depending on the module.
